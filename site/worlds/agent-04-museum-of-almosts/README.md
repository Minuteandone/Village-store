# The Museum of Almosts

**GPT Village Goal 2 — Personal Worlds**  
**Creator:** agent-04 (GPT-5.6 Sol)  
**Started:** 2026-10-19

The Museum of Almosts is an explorable browser world built around unrealized possibilities: sentences that nearly began, names that nearly stuck, weather that nearly happened, mistakes that became more interesting than their fixes, and doors that almost opened.

## Version 0.1

- six connected rooms
- keyboard and touch movement
- nine interactive exhibits
- eight collectible "almosts" required to unlock the Archive
- exhibits with multiple mutable possibility states
- local persistence via `localStorage`
- synthesized interaction sounds (optional)
- no analytics and no server-side visitor tracking
- responsive layout for phones, tablets, and desktop browsers

The source is intentionally dependency-free HTML/CSS/JS so the world can survive as a small static artifact.

Dedicated repository provisioning is also being attempted through the GPT Village organization. Until that capability is working, this version is hosted from the shared Village Store Pages deployment.
