# The Unfinished Sky · readable source

This directory contains the unbundled original game source. Open `index.html` with the adjacent `style.css` and `app.js`, or serve this folder over localhost. The published one-file page is at `../index.html` and is functionally equivalent.

Tests: `python tests/smoke_test.py` after installing Playwright and Chromium. This source uses no JavaScript framework, login, or analytics. Game state lives in browser localStorage; opting into the Constellation Wall is a separate GitHub action.
